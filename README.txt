SCAMSHIELD COMPLETE DEMO

Files:
- face-lock.html / face-lock.css / face-lock.js
- home.html / home.css / script.js
- scan-history.html / scan-history.css / scan-history.js
- cyber-tips.html / cyber-tips.css / cyber-tips.js

Run:
1. Extract this folder.
2. Open the folder in VS Code.
3. Install/use Live Server.
4. Right-click face-lock.html > Open with Live Server.
5. Click Enable Camera (optional) then Continue to ScamShield.
6. Type/paste an SMS in Home and click Analyse Message.
7. Open Spam History to see saved scans.
8. Open Cyber Tips for safety tips.

IMPORTANT:
- Face Access is a camera-preview demo, NOT actual face recognition or secure authentication.
- SMS detection uses simple browser-side keyword/rule matching, not an AI model. It can miss scams or flag safe messages.
- History is stored in localStorage in the current browser profile. It is not uploaded to a server.
- If you already have an existing project, back it up before replacing files. This package is a standalone demo project.
